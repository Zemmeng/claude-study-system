## Big-O 证明（`w01-L1` p.6）

| 关键词 | 用法 |
|---|---|
| *there exist constants* | 定义的开头 |
| *for all n > n₀* | 不等式成立的范围 |
| *upper bound* / *tight bound* | `O` vs `Θ` |

**句式**
1. *We need to find constants `c > 0` and `n₀` such that `t(n) ≤ c · g(n)` for all `n > n₀`.*
2. *Choose `c = …` and `n₀ = …`.*
3. *Then for all `n > n₀`, `t(n) ≤ … ≤ c · g(n)`, so `t(n) ∈ O(g(n))`.*

**满分范例**（`5n + 3 ∈ O(n)`）
> We need constants `c > 0` and `n₀` such that `5n + 3 ≤ c · n` for all `n > n₀`. Choose `c = 6` and `n₀ = 3`. For all `n > 3`, `3 < n`, so `5n + 3 < 5n + n = 6n`. Hence `5n + 3 ∈ O(n)`.

## 为什么 binary search 需要排序（`w02-L1` p.7）

**句式**
1. *The algorithm maintains the invariant that, if `x` is in `A`, it lies in `A[lo..hi]`.*
2. *When `A[mid] < x`, sortedness guarantees that every element in `A[lo..mid]` is less than `x`, so discarding them is safe.*
3. *Without sortedness, this discard step may throw away `x`.*

⚠️ 别答成 *"it halves the range each time"* —— 那是 **what**，题目问的是 **why**。
