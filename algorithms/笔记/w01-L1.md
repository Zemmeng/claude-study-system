# algorithms `w01-L1` 笔记 —— Growth of Functions and Big-O

> 📌 **示例数据。** 笔记**在讲完之后写，内容来自讨论过的东西** —— 他卡在哪、问了什么、我补了什么。不是把课件重抄一遍。

## 他卡住的地方

| 卡点 | 他当时怎么想的 | 点破 |
|---|---|---|
| `n₀` 是干什么的 | 以为是「输入的最小规模」 | `n₀` = 从哪里开始不等式成立；小 `n` 上随便怎样都行 |
| `n ∈ O(n²)` 对不对 | 以为 Big-O 是精确增长率，答「错」 | Big-O 只是 **upper bound** —— 对 |
| 数 basic operation | 把循环外的赋值也算进去 | 只数 innermost loop 里那个 |

## 他问了什么

- 「为什么要两个常数？」→ `c` 管「乘多少倍以内都算」，`n₀` 管「从哪开始」，缺一个定义就不成立
- 「Θ 和 O 考卷上写哪个？」→ 题目问 *tight bound* 写 `Θ`，只问上界写 `O`

## 答题时要写对

- `t(n) ∈ O(g(n))`，不是 `t(n) = O(g(n))`（课件用 `∈`）
- 证明 Big-O：**先写出 `c` 和 `n₀` 的具体值，再验证不等式**（🔴 老师说不写扣分）
