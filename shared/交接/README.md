## 为什么需要它

写文件分区（主 `CLAUDE.md` 的会话类型节）规定：

| 类 | 只许写 |
|---|---|
| **学习类**（`/学` `/作业`） | `<课程>/` 自己那门课的目录 · `学时记录.md` 追加明细行 · **`shared/交接/`** |
| **总控类**（`/总控`） | `shared/` 的账本（台账 · 学习日志 · deadlines · 公告 · 提醒） |

所以学习会话**做完了事也改不了账本**。它把「该改哪张表的哪一行」写成一份交接单，
`/总控` 开场第 0 步消费掉。

🔴 **不写交接单的后果是真的**：原项目里一份作业在作业会话里提交完，
33 分钟后总控出看板时读的还是过期的 `学习日志.md`，
**把一份已经交掉的作业排成了周六 8 h 的主攻**。

## 命名

```
shared/交接/交接-<课程>-<deck 或作业代号>-<一句话>-<YYYY-MM-DD>.md
```

🔒 **`<deck 或作业代号>` 必须有**（`w05-L1` / `A1` / `Quiz1`）——
`学.md` 和 `作业.md` 的开场第 0 步用 `ls shared/交接/*<deck>*` 找它，**名字里没代号就找不到**。

例：`交接-algorithms-A1已提交-2026-10-08.md` · `交接-networks-w02-L1讲完-2026-10-12.md`（样例见 `shared/交接/已处理/`）

## 四节结构（🔒 **唯一的节名定义** —— `学.md` 和 `作业.md` 都指向这里）

```markdown
## 1. 事实
交了没有 / 讲到第几页（viewer 页）/ 完成度 / 提交平台上的 attempt

## 2. 该改哪张表的哪一行
🔴 逐条列，带行号和「现在写着什么 → 实际是什么」：
- `shared/lecture台账.md` 第 N 行：「讲到」列 → viewer p.X
- `shared/学习日志.md` 第 N 行：现在写「停在 …」→ 已完成
- `shared/deadlines.md` 第 N 行：标已提交
- `shared/学时记录.md`：顶部累计 +X h（🔒 明细行本会话已追加，累计表归总控重算）
- `shared/公告.md`：本讲挖到的 🔴 考点 / ⚪ 不考（带 viewer 页码 + 时间戳 + 老师原话）

## 3. 留给 /总控
学习会话里撞见但不能当场做的杂活（扫邮箱 · 归档 · 转录 · 装东西 · 改脚本）

## 4. 还没并的过程细节（可选）
下一步该问什么 · 没讲完的块停在哪
```
