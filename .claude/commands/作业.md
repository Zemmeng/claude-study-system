# `/作业 <课程> <代号>`

例：`/作业 algorithms w06-A1` · `/作业 networks w08-project1`（课程 key 取自 `shared/配置.json`）

> **这个会话只做一件事：把这份作业推到交掉。**

---

## 🔒 第零步：登记这个会话（**开场第一件事，5 秒**）

往 `shared/活动会话.tsv` 追加一行（tab 分隔）：

```
<开始时间 YYYY-MM-DD HH:MM>	作业	<一句话说在做什么>	active
```

**收尾时**（说「仄梦大王」那一步）把该行末尾的 `active` 改成 `done`。

> 为什么：他 2026-09-02 明确要求「总控对话开的时候得知道现在有哪几个对话还活着、正在学什么」。
> Claude Code 桌面版（CCD）的 `list_sessions` 有 `isRunning`，但**实测全是 false**，而且 hook 是 shell 调不了 MCP —— 只能靠登记。

🔒 **并行时的写文件分区**（他 2026-09-02 起同时开多个会话）：
**这个会话只写 `<课程>/作业/` 这一份作业自己的文件**。`shared/` 下的账本（`lecture台账.md` · `学习日志.md` · `deadlines.md`）
**只有 `/总控` 会话能动** —— 三个会话同时改同一张表会互相覆盖。

---

## 🔒 第一步：先确认这一份作业允许我做到哪一步

**翻这一份作业自己的 spec / Canvas 页面**，看它的 AI 条款怎么写。两条线（细则以主 `CLAUDE.md` 的「学术诚信」节为准）：
· **允许 AI 的作业** → 在 spec 允许的范围内放手用 AI，spec 要求声明的如实声明；
· **不允许 AI 的作业** → 🔒 **最终交上去的东西由他自己产出**，我做辅助和引导（讲概念 · 解释报错 · 陪 debug · 出练习题 · 检查格式 · 指出哪一步错了）。

❌ **不许拿同门另一份作业、更不许拿别门课的措辞去推。**
　（犯过：把同门另一份作业的条款套到这一份上，据此连着两次拒绝帮他 —— 而这一份题面里根本没有 AI 条款。）

查完把结论写进**本会话的交接单**，开一节 `## AI 政策核查结论`（`作业代号 | 政策出处 | 核查日期 | 能做到什么程度`），
**留给 `/总控` 并进主 `CLAUDE.md` 的分级表** —— 改根目录 `CLAUDE.md` 属于架构，是总控的活。

🔒🔒 **AI 政策以主 `CLAUDE.md` 的「按课分级」表为准 —— 那是唯一出处，连同它下面的细则节一起读。**
❌ **这里不再复制那张表**（2026-09-03 审计发现这份副本漏了好几行，表一旦有两份就会漏）。

🔒 **「未核」的一律按最严的走** —— **不代写、只审查**，核完再按主表那一行放宽。
❌ 不许因为「那份 spec 没提 AI」就默认放行。

🔴🔴 **读题目原件之前先看主表那一行**：写着 **「不许把整份 spec 喂给 AI」** 的作业，
**只读 `<代号>-要点.md`，不读 `-spec.pdf` / `-spec.md` 全文** ——
spec 全文就躺在仓库里，**读进来就收不回去了**（犯过一次）。

---

## 第二步：只读这些

1. `<课程>/作业/<代号>-spec.pdf` 或 `-questions.pdf` / `-handout.pdf` —— 题目原件
2. `<课程>/作业/<代号>-要点.md`　⚠️ **不存在时**读那份作业自己的「当前状态 / 过程档案」文件
   （例：`<课程>/作业/<代号>-当前状态.md`） —— 已有的拆解（分值 / 格式 / 罚则）
3. **他当前的作答文件** —— 🔒 **别默认叫 `-answers.tex`，按那份作业自己的档案定**
   　⚠️ **同一份作业有多个版本时（初稿 / 重做版 / 最终版）先确认哪个才是要提交的**，别把旧版当成现行版发给他
   　（他 08-31 的原话：「这是最终版的 pdf **不要和之前的混淆**」）
0. 🔴🔴 **`ls shared/交接/*<课程>* shared/交接/已处理/*<课程>*`** —— 有就先读，**以它为准**
   （上一个作业会话停在哪、交了没有、该改哪张表，**只写在交接单里**）
4. 🔴 **`<课程>/CLAUDE.md`（必读）** —— 该课的 hurdle / 权重 / 提交物在这儿；**某份作业的 AI 边界若在这里有补充，也以这里为准**（⚠️ 一份作业的放宽**不自动沿用**到同课的下一份，每份都按自己的 spec 重核，结论记进主 `CLAUDE.md` 分级表）
5. `shared/deadlines.md` —— **只 grep 这一份作业那一行**（due / 迟交规则 / 交在哪）
6. 🔒 **`shared/学习日志.md` 的 `## ⏭️ 当前状态` 节里这份作业那一段** —— **上次停在哪**
   　（导航层只带断点节的头两行，**未完的作业进度不在那儿**，必须自己来这里读）

❌ **不要读**：课件进度 · `lecture台账.md` · 别的作业
⚠️ `shared/学时记录.md` —— **只读该门课最后一行 + 底部实测速度，不通读**
  🔒 **做作业的时间记进那门课自己的表（`## <课程>` 节小计之前，五列），不是文件末尾的「不计入学时的基建」节** —— 09-17 有一条 5 h 40 放错过，总控搬回来的。只有排版/归档/装软件这类才进基建节。

## 🔒 第三步：两份 PDF 一起发

`SendUserFile` 一次发两份，`display: "render"`（仅 Claude Code 桌面版；CLI 下改为报出两份 PDF 的路径）：

| 发什么 | 注意 |
|---|---|
| ① 题目原件 PDF | —— |
| ② 他当前的作答 PDF | **发之前先重编译**（`.tex` 改过没编译就发 = 发了个过期的） |

他要左右对照着写，不用回翻聊天记录。**每做完一题就重编译 + 重发一次。**

---

## 排版规矩

- 编译这类基建命令**我自己跑**，不贴给他
- 🔒 **提交物的 `.tex` 正文 100% 英文**，中文只许出现在 `%` 注释里
- 🔒 **提交用的 `.tex` 不要加载 `xeCJK`** —— 手滑打了中文会当场编译报错，而不是悄悄排进 PDF
- **排版时只搬运，不修改**。发现内容有问题就单独指出来问他，不许在排版里悄悄改掉
- 那份作业的 spec 要求声明 AI 使用的，**边做边记在 `.tex` 的注释里**，别交前才回忆

## 收尾（四件，缺一不可）

> 🔴 **2026-09-03 补**：这份文件原来**整份没有收尾节** —— 全文止于「这个会话里不做的事」。
> 结果是每个作业会话收尾时都得自己想一遍该干什么（09-02 那个作业会话就是自己想出来要写交接单的，
> 没有任何文件教过它）。

1. 🔑 **写交接单** → `shared/交接/交接-<课程>-<事由>-<YYYY-MM-DD>.md`
   🔒 **节名照 `shared/交接/README.md` 的四节，别自造**：

   | 节 | `/作业` 会话在这一节写什么 |
   |---|---|
   | `## 1. 事实` | 交了没有 · 交的是哪个文件 · 完成度 · Canvas attempt |
   | `## 2. 该改哪张表的哪一行` | `deadlines.md` 标已提交 · `学习日志.md` 哪几行过期了（**给行号**）· `学时记录.md` 顶部累计 +X h（🔒 明细行本会话已追加，别重复写）<br>**AI 政策核查结论**（如果第一步核过）—— 留给总控并进主 `CLAUDE.md` 的分级表 |
   | `## 3. 留给 /总控` | 做作业时撞见的杂活 |
   | `## 4. 还没并的过程细节` | 给组员的草稿 · 下一步该问什么 |
2. **`shared/学时记录.md` 追加明细行**（🔒 只追加，**顶部累计表和各科「小计」行都不许动** —— 两个都是总控重算的派生值，顺手改小计会当场 ❌`[4]`）
   ⚠️ **只记做题/写作业的时间**；编译、排版、归档算基建，**不计入**
3. 🔒 **`shared/活动会话.tsv` 里自己那行**：`active` → `done` · **第 3 列**末尾补一句刚完成了什么 · 🔑 **行尾再补第 5 列 = 收尾时间 `YYYY-MM-DD HH:MM`**
   ⚠️ **第 4 列（状态）只许是 `done` 五个字母**，别的话写第 3 列 —— `导航.py` 按它精确匹配
   ⚠️ **第 5 列不填，导航层的「🎉 刚收尾的」就会漏掉你**（它没有收尾时间时只能退回用开始时间，跨天的会话会被算成「40 h 前」而不显示）
4. **跑 `python3 shared/工具/检查.py`，确认没有 ❌**
   ⚠️ **`[12]` 报 ⚠️ 是正常的** —— 你收尾时刚写了一份交接单，它就是在提醒 `/总控` 来收。
   🔒 判据是**没有 ❌**，不是「全绿」。
5. 全部做完，说「仄梦大王」
