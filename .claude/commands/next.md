   **宏是 `\pbarA{宽cm}{已完成比例}{已放出比例}{深色}{浅色}`**，每门课四条：`课件` / `tute`（用练习平台的课是 `Ed`）/ `quiz` / `作业`。
   🔒 **各门的小标题只放课程代码，不放学时**（2026-09-15 22:22 他定：「把完成进度的面板的时间隐藏掉」）—— 学时只在抬头和「已经完成的」分组行出现。

   🔒 **三条口径不许改：**

   | | |
   |---|---|
   | **分母** | **只算「已放出的材料」**，不是全学期 \arr **条满 = 欠帐清零**。<br>❌ 按全学期算 \arr **学期过半之前条永远三分之一**，他每次打开都像没学过东西 |
   | **三段** | 深 = 已完成 · 浅 = 已放出还欠着 · **灰 = 本学期还没放出**（第三参数给 `1.0` 就是「已放出的全在这了」）|
   | **做一半** | **按做了几成折算**（`w04` tute 八题做了 1.5 题 = **0.2 份**）。❌ 不是「只认全清」—— 他 08-25 明确选了折算 |

   **分子分母从哪取**（一律现算，不许抄上一版）：

   - **tute** = 份数 / 项数（按各课自己的习惯：例 algorithms 按 `tute/wNN.pdf` 份数 · networks 含 workshop 和 Lab）
   - **quiz** = **已放出的份数** —— 🔴 **不许写死数字**
     （原来写「现在只放出 3 次」，到 W6 已放出 4 次；分母偏小 \arr W2/W3/W4 满分就成了条满
     \arr **09-04 到期、前置一页没讲的 Week 05 Quiz 会从看板上消失**）
     🔒 **算法**：`Week 02` 到 `K`，`K` = 当前教学周（**本周五 lecture 已过**）否则当前周 −1；份数 = `K−1`。
     ⚠️ **别用「grep deadlines 数行数」当兜底** —— 那张表里连**还没放出**的 quiz 也有行（日期是从 Canvas Grades 页确认的截止日，不是放出日），
     数出来会偏大。**就按上面那个公式算**，拿不准就问他「这周五的 algorithms lecture 上了没有」。
   - **Ed**（只有配了练习平台存档的课）= `<课程>/Ed/README.md` 里的**核心条目数**（不含选做 / extra 条目）
   - **作业** = 已放出的份数；🔒 **已提交的一律 1.0**（提交日期查交接单或 `学时记录.md`）；只有真正进行中的才估
   - **空条**：那一类这学期还没开张 \arr 第 2、3 参数都给 `0.0`，标注写「未放出 / 无 quiz / 09-21 起」

   ⚠️ **`\pbarA` 里的 `\path[use as bounding box]` 那一行不许删** —— 没有它，比例为 0 的空条会把同一行的标注挤到下一行（08-25 踩过）。

## 排版注意（踩过的坑）

- 🔒 **每张表都必须有表头，而且要加 `\endhead`**（2026-08-11 踩过：给「已经完成的」表加了课程分组行
  之后把表头弄丢了，四列没标签，他一眼看出来）。
  表头用 `\rowcolor{band}`（灰），**分组行用 `\rowcolor{okbg}`（浅绿）** —— 两个同色会糊在一起。
  `\endhead` 保证跨页时表头重复，**页数以现编译结果为准**（实测 7 页），表一定会跨页。

- 🔒 **四套字体必须全设齐，缺一套就会「大大小小」**（2026-08-11 他一眼看出来的）：
  ```
  \setCJKmainfont{PingFang SC}      % 黑体，和 Helvetica 同族；宋体+Helvetica 混排很别扭
  \setCJKmonofont{PingFang SC}
  \setmainfont{Helvetica Neue}
  \setmonofont{Menlo}[Scale=MatchLowercase]   % ← 关键，让 x-height 对齐
  ```
  **漏掉 `\setmonofont` 时，所有 `\texttt{}` 会掉进 Latin Modern Mono** —— 那个字体在 10pt 下比 Helvetica
  大一圈也宽一截，夹在中文里一跳一跳。**`Scale=MatchLowercase` 才是「看起来一样大」的真正开关。**
- 🔒 **表格列一律用 `L{}` 不用 `p{}`**（preamble 里已定义 `\newcolumntype{L}`）。
  `p{}` 默认两端对齐，遇到 `Integer.parseInt` 这种长等宽词，会把同行中文拉成「6 个 命 令 行 参 数」
- 🔒 **`\texttt{}` 只给「代号 / 路径 / 代码」**：`w03-L1` · `tute/w03.pdf` · `Integer.parseInt` · `.mwb`。
  **练习题和作业的「名字」用 `\textbf{}`** —— `Mars Rover (Map)`、`Tutorial 3` 是标题不是代码，
  用等宽会又宽又跳
- CJK 字体见上（**不要再用 Songti SC**）
- ✓ ✗ ⚠ 用 `pifont` 的 `\ding{51}` / `\ding{55}` / `\ding{115}`，**不要直接打这些字符**
- 🔒 **箭头用 `\arr` 宏**（已在 preamble 里定义 = `\,$\rightarrow$\,`）。
  **绝对不许直接打 `→`** —— Songti SC 和 Helvetica Neue 都没这个字形，**会渲成豆腐块 □**（2026-08-11 他一眼看出来了）
- 🔒 **不许用反引号 `` ` `` 包代码** —— LaTeX 会把它渲成弯引号 `'`。用 `\texttt{...}`
- **不要用 emoji**，字体渲不出来
- 表格列宽给中文留够 —— 课程名那一列（例：「algorithms」）至少 `p{2.35cm}`（窄了会被截断）
- `%` `&` `_` `#` 要转义
- 🔒 **发之前自己看一眼**：`pdftoppm -png -r 105 -f 1 -l 1 dashboard.pdf out` 然后 Read 那张图。
  **不许没渲染就发** —— 上面两个坑都是发出去之后才被他发现的
