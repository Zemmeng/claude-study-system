# `/学 <课程> <deck>`

例：`/学 algorithms w05-L1` · `/学 networks w04-L1`（课程 key 取自 `shared/配置.json` 里的每门课）

> **这个会话只做一件事：把这份 deck 讲完。**
> 讲 → 出题 → 他答 → 我批 → 记账 → 收尾卷。讲完这份就收尾，不接别的活。

---

## 🔒 第零步：登记这个会话（**开场第一件事，5 秒**）

往 `shared/活动会话.tsv` 追加一行（tab 分隔）：

```
<开始时间 YYYY-MM-DD HH:MM>	学	<一句话说在做什么>	active
```

**收尾时**（说「仄梦大王」那一步）把该行末尾的 `active` 改成 `done`。

> 为什么：他 2026-09-02 明确要求「总控对话开的时候得知道现在有哪几个对话还活着、正在学什么」。
> Claude Code 桌面版（CCD）的 `list_sessions` 有 `isRunning`，但**实测全是 false**，而且 hook 是 shell 调不了 MCP —— 只能靠登记。

🔒 **并行时的写文件分区**（他 2026-09-02 起同时开多个会话）：
**这个会话只写 `<课程>/` 自己那门课的目录**。`shared/` 下的账本（`lecture台账.md` · `学习日志.md` · `deadlines.md`）
**只有 `/总控` 会话能动** —— 三个会话同时改同一张表会互相覆盖。
⚠️ 例外：`shared/学时记录.md` 是**纯追加**的，可以写（只追加明细行，**不要改顶部累计表** —— 那个留给总控重算）。
  🔒 **追加到该课程自己那张表的末尾（`## <课程> …` 节的「小计」行之前），五列格式 `| 日期 | 时段 | 时长 | 内容 | 产出 |`。❌ 不许追加到文件末尾** —— 那是「不计入学时的基建」节，`检查.py [4·明细]` 按节求和会漏掉（09-14 · 09-15 · 09-16 · 09-17 **四次**都放错了，总控搬回来的 —— 🔴 **`/作业` 会话同理**：做作业的时间也记进那门课自己的表，不是基建节）

## 第三步：讲

照主 `CLAUDE.md` 的**四节**走：**「带我学一讲的方式」+「学习流程」+「批改形态」+「讲解形态」**（🔒 其中第 9 条：**不许照搬课件和老师的抽象措辞，先给他能「看见」的场景再上术语** —— 09-14 他的原话「越来越抽象了 我每次都有点听不懂 讲的生动形象一点啊」）
（🔴 2026-09-03 扩：四类标记 🔴/⚪/💡/⚠️ 和「讲到哪校到哪」写在**「学习流程」**节，
答题表达套件写在**「批改形态」**节 —— 只指第一节的话，校对规程和套件都够不到）。

六条最容易忘的：

- 🔒 **题目一律全英文，写成考卷的样子** —— 题干、选项、指令都是英文，不夹中文（09-03 23:58 他抓到一次「咋还变中文回答问题了？」）。他用英文答，批改时才用中文
- **一块 ≤ 5 页真内容**，讲完必停等他回话（预扫的「分块建议」节已经现成算好了）
- **页码一律按 viewer 物理页**（offset 在对照表顶部记着）
- **每块按题型分层表出题**：块中出判断/选择/填空 2–3 道；**justify 最多 1 道**，且只在那个点是全讲最硬的时候才出，其余留到收尾卷；选项必须带 `(a)(b)(c)(d)`
- 🔒🔒 **出任何一道题之前跑主 `CLAUDE.md` 自检清单 ④「越界检查」**：标出处（哪一页）→ 列前置 → 逐个核范围。
  ⚠️ **对「批改中临时想到的补题」尤其致命** —— 开讲前的清单只跑一次，补题天然绕过那次检查
- 🔒 **出题编号在一个 deck 的会话内连续编** —— 第二块从 Q6 接着编，**别每块都从 Q1 重来**
  （他 08-22 12:15 的原话：「怎么又从 Q1 开始」）

## 收尾（五件，缺一不可）

> 🔴🔴 **2026-09-03 重写**：原来写的是「台账「讲到」列推进 + 断点清回「无」」——
> 那两张表（`lecture台账.md` · `学习日志.md`）**这个会话根本没有写权限**（见上面第零步的分区表，
> `检查.py [12]` 也已经上了门禁）。**那是一条写不进去的指令。**
> 正确做法：**要总控改哪张表的哪一行，写进交接单。**

1. 🔑 **写交接单** → `shared/交接/交接-<课程>-<deck>-<YYYY-MM-DD>.md`
   🔒 **节名照 `shared/交接/README.md` 的四节，别自造**（三份文件曾各写一套，总控没法消费）：

   | 节 | `/学` 会话在这一节写什么 |
   |---|---|
   | `## 1. 事实` | 讲到第几页（**viewer 页**）· 讲+答+批齐了没有 · 收尾卷出了没有 |
   | `## 2. 该改哪张表的哪一行` | `lecture台账.md`：「讲到」列 → viewer p.X · 字幕列 · 到场列<br>`学时记录.md`：**顶部累计表 +X h**（🔒 明细行本会话已经追加了，**这里不要重复写**）<br>`公告.md`：本讲挖到的 🔴 考点 / ⚪ 不考（带 viewer 页码 + 时间戳 + 老师原话）<br>`学习日志.md`：断点该清成「无」；没讲完就写停在哪、**欠哪几道题（题目全文）**、编到 Q 几 |
   | `## 3. 留给 /总控` | 讲课中途撞见的杂活（扫邮箱 · 归档 · 转录 · 装东西 · 改脚本）|
   | `## 4. 还没并的过程细节`（可选）| 下次接手该先看什么 |
2. **`shared/学时记录.md` 追加明细行**（🔒 只追加，**顶部累计表和各科「小计」行都不许动** —— 两个都是总控重算的派生值，顺手改小计会当场 ❌`[4]`）
3. **出这一讲的收尾卷** → `<课程>/收尾卷/<deck>-收尾卷.md`
   跳过了就在交接单的「断点」那节写「⬜ 收尾卷未出」
4. **笔记** `<课程>/笔记/<deck>.md` —— 内容来自讨论过的东西（他卡在哪 · 问了什么 · 我补了什么），
   **不是把课件重抄一遍**；**他问过「XX 啥意思」的词进 `<课程>/答题表达套件.md`**
5. 🔒 **`shared/活动会话.tsv` 里自己那行**：`active` → `done` · **第 3 列**末尾补一句刚完成了什么 · 🔑 **行尾再补第 5 列 = 收尾时间 `YYYY-MM-DD HH:MM`**
   ⚠️ **第 4 列（状态）只许是 `done` 五个字母**，别的话写第 3 列 —— `导航.py` 按它精确匹配
   ⚠️ **第 5 列不填，导航层的「🎉 刚收尾的」就会漏掉你**（它没有收尾时间时只能退回用开始时间，跨天的会话会被算成「40 h 前」而不显示）
   （导航层会把 30 h 内 `done` 的显示出来，**下一个会话就不会把已完成的当成没做完**）

做完这五件，再跑 `python3 shared/工具/检查.py`，**确认没有 ❌**，然后说「仄梦大王」。
⚠️ **`[12]` 报 ⚠️ 是正常的** —— 你刚写了一份交接单，它就是在提醒 `/总控` 来收。
