# 预扫 —— 拿到新课件的第一件事

> **他 2026-08-21 提的**：「每次收到新课件或资料，应该先快速扫一遍这份讲了什么。」
>
> **为什么必须机械做**：主 `CLAUDE.md` 第 17 条那个坑（networks `w03-L1` 当成独立的 8 页，
> 实际它从页码 38 开始，是 `w02-L2` 的续篇）就是「凭 deck 名字排页码」造成的。
> **归档 ≠ 知道它讲什么。** 不扫就排计划 = 拿假数据排。

## 什么时候跑

| 触发 | 动作 |
|---|---|
| **归档任何一份新 `课件/wNN-LN.pdf`** | 归档完**当场**跑，别等到要讲的时候 |
| 台账里某个 deck 还标 `❌未开始`，而 `_预扫/` 里没有它的摘要 | 补跑 |
| **要给某门课排页码/估时之前** | 摘要不在 → 先扫，再排（主 `CLAUDE.md` 「②b 前置链检查」） |
| 他问「这份讲什么 / 要多久」 | 🔒 **直接扫，不许问他「要不要我扫一遍」**（08-21 01:35 定的） |

## 怎么跑

```bash
python3 shared/工具/预扫.py <课程>/课件/wNN-LN.pdf --full --save
```

🔴🔴 **跑完必做一步（2026-09-03 加，09-02 栽过）**：脚本只有 `pdftotext`，**读不出图片页，会把它们当成空页或动画重复帧**。
**凡是报「空页」或「动画重复帧」的页，落台账之前必须渲染出来人眼看一遍**：

```bash
pdftoppm -png -r 80 -f <页> -l <页> <deck>.pdf /tmp/chk
```

脚本一次跑完五件事，全部**实测**，不猜：

| # | 查什么 | 机械判据 |
|---|---|---|
| ① | **物理页数** | `pdfinfo` 的 `Pages:` |
| ② | **是不是续篇** | 看 **offset**：`offset ≤ 2` = 新一章；`+33` / `+37` 这种 = 续篇，前面还有东西。<br>🔴 **不许只看封面那一页** —— 见下面的封面陷阱 |
| ③ | **页脚 offset** | 对候选 `k ∈ [-5,80)` 多数表决：有几页满足「物理页 + k 出现在该页的整数 token 里」。<br>命中率 `< 50%` → 判定**这份 deck 没有页脚页码**（有的课件页脚是 `Page [N]` 格式，脚本已单独处理） |
| ④ | **动画版检测** | `pdftotext -layout` 逐页取正文 → 滤掉页脚号、版权行、图里的**单字母节点** → 剩下的小写去空白当**文字签名** → **相邻页签名相同 = 同一张 slide 的动画帧** |
| ⑤ | **逐页骨架** | 每页第一条非版权非纯数字的行当标题，其余行当内容；动画段合并成一行标 🎞️ |

### 🔴 封面陷阱（2026-08-21 实测挖出来的）

**networks 每一份 deck 的封面（title slide）页脚都印 `1`** —— 但那是 title slide 自己的编号，
**和正文的页码是两套**。实测：

| deck | 封面页脚 | 正文从 | 真实情况 |
|---|---|---|---|
| networks `w03-L2` | `1` | `1` | 真的从 1 开始 |
| networks **`w03-L3`** | **`1`** | **`11`** | 🔴 **续篇** —— 封面在骗人 |
| networks **`w04-L1`** | **`1`** | **`35`** | 🔴 **续篇** —— 封面在骗人 |

🔒 **所以判续篇一律看 `p.2` 的页脚，不看 `p.1`。**
脚本的 offset 用**多数表决**，封面那个 `1` 只是一个 outlier，不影响结论 —— **但人工核对时极易被骗**。

**实测过的 offset（证明「没有统一规则，只能一份一份量」）：**

| deck | offset | 说明 |
|---|---|---|
| algorithms `w03-L1` | **+1** | 46 页 / 末页页脚 47 |
| algorithms `w03-L2` | **0** | 24 / 24 |
| algorithms `w04-L1` | **+1** | 32 页，30/32 实测命中 |
| algorithms `w04-L2` | **0** | 106 页 |
| networks `w03-L1` | **+37** | 🔴 续篇，接 `w02-L2` |
| networks `w04-L1` | **+33** | 🔴 续篇，接 `w03-L3` |
| 某课（页脚 `Page [N]` 格式）全部 | **0** | 脚本已单独处理 |
| networks **`w06-L1`** | **+24** | 🔴 续篇，接 `w05-L2`（09-02 实测：p.2 = 页脚 26，末页 = 39）|
| networks **`w06-L2`** | **+38** | 🔴 续篇，接 `w06-L1` |
| 某课 `w06-L1` | **0** | 36 页 / 页脚对齐 |
| 某课 **`w06-L2`** | **0** | ~~09-02 判成「没有页脚页码」~~ 09-04 实测改正：页脚号有，格式在 `N` 和 `-N-` 之间跳，脚本没认出（p.18/19 没印）。⚠️ **脚本报「没有页脚页码」时先看渲染图再信** |

## 产出什么、存哪里

**一份 deck 一个文件：`<课程>/课件/_预扫/<deck代号>.md`**（例：`networks/课件/_预扫/w02-L1.md`）

🔴 **2026-09-03 改**：原来写「必须有这七节，顺序固定」，**是死条文** —— 脚本只产前三样。
**实测 19 份产物有三种格式**：11 份编号七节（人工写的老格式）· 1 份 `## 人工三项` · 🔴 **7 份只有脚本段、人工层一个字没补**（09-02 `--save` 批量跑的 W6）。
🔒 **新产物统一按下面这套写**（脚本段 + 人工层），老的 11 份不用回头改。
⚠️ **看到只有脚本段的，就是人工层欠着** —— 那份 deck 的**前置链还没查过**，别当成「没有前置警告」。

🆕 **2026-09-04 起 `--save` 还顺手落 `_预扫/<deck>.txt`（全文，带 `===== <deck> viewer p.N =====` 页标）**；`python3 shared/工具/文字层索引.py [课程]` 重建每门课的 `_预扫/_全课文字层.txt`（全课 deck 按周序拼，查「某词首次出现在哪」一次 `grep -n` 就够）。
🔒 **批量补人工层/骨架的 agent 只读这两样 + 台账行 + 一份样板，工具调用 ≤ 20 次，不许自己 pdftotext** —— 他 09-04 问「为什么烧那么多 token」，实测病根就是 agent 逐页读 PDF + 逐词 grep 十份 deck（每个 agent 10–14 M 输入 token）。

**脚本 `--save` 自动产的（`## 逐页骨架` 之前那几行 + 表）：**

| 内容 | 说明 |
|---|---|
| **机械事实** | 物理页数 · **页脚 offset（实测）** · 是不是续篇 · **不同画面数**（动画重复帧多少） |
| **动画段清单** | 连续同签名的页区间 + 那段的标题 |
| **`## 逐页骨架`** | 表格：viewer 页 / 页脚 / 标题 / 一句话内容 |

**人工在下面补的（脚本产不了）：**

| 节 | 放什么 |
|---|---|
| **`## 人工三项`** | ① 课件内部的 Lecture 编号 + 标题 + lecturer　② 它在整门课的位置　③ **🔴 前置警告** —— 正文用到了本 deck 没定义过的符号/术语吗？在哪一页用、定义在**哪份 deck 的哪一页**（⚠️ 只列**真前置**）|
| **`## 📗 其他资料对应段落`** | 教材章节 · 练习平台 lessons（例：`<课程>/Ed/` 下的存档）· tute 讲义 —— **哪一页对应哪个文件的哪一节**（这一节会抄进对照表顶部）|
| **概念清单** | 本 deck **新引入**的术语，**一律英文**（考卷印什么就写什么）|
| **分块建议** | 按内容分，🔒 **一块 ≤ 5 页真内容**；标出铺垫页（讲快）和硬核页（必出题）|
| **估时** | 见下表，**含出题和批改** |

**估时口径**（和 `next.md` 的看板一套）：

| 页型 | 单价 |
|---|---|
| 概念 / 要动手算的页 | **10–12 min/页** |
| 背景 / 动机 / 类比页 | **5–7 min/页** |
| 行政 / 封面 / 版权页 | **~1 min/页** |
| **一整份收尾卷**（出题 + 他答 + 我批） | **30–45 min** |

🔒 **权威口径在 `shared/工具手册.md` 的「看板」节** —— 那里是唯一出处，这里是它的副本，
改一处要两处一起改。（2026-09-03 校正：原来写 8–10 / 3–4 / <1，和工具手册对不上。）

⚠️ **「页数少了」不等于「省时间」** —— algorithms `w04-L2` 扫完 106 → 58 个画面，
估时反而从 2.5 h **上调到 3.5 h**，因为概念点比页数暗示的多。**扫是为了准，不是为了砍。**

## 🔒 扫完必须落地到台账

**只留在对话里 = 白扫**（主 `CLAUDE.md` 第 15 条）。

🔒 **谁落账看会话类型**：`/总控` 直接改 `shared/lecture台账.md`；
**`/学` `/作业` 把下面这些写进交接单的 `## 2`**（那两类会话动不了台账）。

要落的内容：

- 页数列 → 填**物理页数**
- 备注列加一行：`✅ 已预扫（<日期>）：<物理页> 页 / offset <±N> / <续篇 or 新一章> / 真内容 <N> 页 / 估时 ≈<N> h` + **指向 `课件/_预扫/<deck>.md` 的指针**
- 有前置警告的 → 🔴 **写进备注列**，不要只留在预扫文件里
  （🔒 2.0 起台账也不再自动注入了 —— 但台账是 `/学` 开局清单里**必 grep** 的，
  　预扫摘要只在点名那份 deck 时才读。写进台账 = 排任何页码时都会撞见）

### 第二个落点：对照表骨架

台账之外，**还要建 `<课程>/字幕/<deck>-对照.md` 的骨架**（🔒 **文件已存在就跳过，绝不覆盖**）：
顶部写 **offset 口径 · 动画段清单 · `## 📗 其他资料对应段落`**，逐页表留空。
（这样 `/学` 会话开局就不会卡在「先建对照表」上。）

### 什么时候跑 —— 三条路由

| 谁 | 什么情况 | 怎么办 |
|---|---|---|
| **`/学`** | **就是本 deck** 缺预扫摘要 | ✅ **当场跑** —— 这是**唯一允许在学习会话里做的基建**（不跑没法排页码） |
| **`/学` · `/作业`** | **别的 deck** 缺 | ❌ 不当场做 —— **写进交接单的 `## 留给 /总控` 节** |
| **`/总控`** | 批量补 | ✅ 固定八件之三 |

## 三条不许

1. ❌ **不许写「疑似 / 待确认 / 真内容多少页不清楚」然后搁着** —— 能跑命令查清的事就当场跑。
2. ❌ **不许拿预扫结果去动「讲到」列** —— 那一列只填「讲+答+批」齐的页码，预扫不是学习。
3. ❌ **不许把预扫摘要当讲解发给他** —— 它是给我排计划用的索引，讲课仍然按主 `CLAUDE.md` 的流程一块块讲。
