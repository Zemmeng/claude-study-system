## 1. 五步上手

```bash
# ① 改配置
$EDITOR shared/配置.json

# ② 建课程目录（以 cs101 为例），放进第一份课件
mkdir -p cs101/{课件/_预扫,字幕,笔记,收尾卷,作业,tute,教材,例卷,录音}
cp ~/Downloads/lecture1.pdf cs101/课件/w01-L1.pdf

# ③ 预扫这份课件（页数 · offset · 骨架落盘）
python3 shared/工具/预扫.py cs101/课件/w01-L1.pdf --save

# ④ 清空示例：删两门示例课，账本只留表头和顶部说明
rm -rf algorithms networks

# ⑤ 跑到全绿
python3 shared/工具/检查.py
```

然后改 `CLAUDE.md` 里带 ✏️ 的三节（关于他 / 作息 / 课表），启动 `claude`。

## 2. 配置文件

`shared/配置.json` 是**唯一需要按学期改的配置**。所有脚本都通过 `shared/工具/配置.py` 读它，不再写死课程名。

```json
{
  "semester": { "name": "2026 S2", "year": 2026 },
  "courses": [
    {
      "key": "cs101",
      "code": "CS101",
      "name": "算法",
      "aliases": ["算法", "algo"],
      "lecture": "周五 09:00–11:00",
      "tute": "周三 15:00"
    }
  ],
  "extra_core_files": []
}
```

| 字段 | 必填 | 说明 |
|---|:-:|---|
| `semester.year` | ✅ | 导航层解析 `MM-DD` 日期时补的年份 |
| `courses[].key` | ✅ | **同时是课程目录名**和账本里 `## <key> …` 节标题的第一个词 |
| `courses[].code` | | 课程代码，只用于显示 |
| `courses[].name` | | 中文名。`deadlines.md` 的「课程」列写中文名也能被认出来 |
| `courses[].aliases` | | 其他叫法，导航层按它把「网络」「net」都归到同一门课 |
| `courses[].lecture` / `tute` | | 只用于显示和排计划参考 |
| `extra_core_files` | | 某门课有自己的唯一数据源时登记在这里（例：`"cs101/Ed/README.md"`），`检查.py` 会要求它存在并扫其中的死链接 |
| `prescan_footer_patterns` | | 可选。`预扫.py` 判断「这行是版权页脚」时额外用的正则，例如 `["university of xxx"]` |

验证：`python3 shared/工具/配置.py` 会打印解析结果，JSON 写错时报出行号。

## 3. 课程目录约定

| 约定 | 为什么 |
|---|---|
| 课件命名 `wNN-LN.pdf`（第 NN 周第 N 讲）| 台账、预扫、对照表、检查脚本都按这个代号互相引用 |
| **页码一律按 viewer 物理页报** | 页脚印的 slide 号和物理页的差值每份 deck 都不一样。差值（offset）记在预扫摘要和对照表顶部 |
| 转录命名 `<deck>.srt` + `<deck>.txt` | 台账「字幕」列写 `` `w01-L1.srt/.txt` ``，`[9]` 会核两个文件都在 |
| 对照表 `字幕/<deck>-对照.md` 必须有「📗 其他资料对应段落」一节 | 它是唯一有硬门禁的文件，「还该看什么」挂在这里，开讲时自然看见 |
| 每门课一份 `<课程>/CLAUDE.md` | 考核权重、hurdle、考试形式。回答这类问题前必须先读 |

## 4. 账本格式契约

脚本用正则解析账本。**下表是必须保持的格式**，其余自由写。

| 文件 | 解析者 | 必须保持的格式 |
|---|---|---|
| `lecture台账.md` | `检查.py` `[8][9][14][1·语义][G]` · `导航.py` | 每门课一节 `## <key> …`；表格 7 列：`\| 周 \| deck \| 页数 \| 讲到 \| 字幕 \| 到场 \| 备注 \|`；deck 写成 `` `w01-L1` ``；「讲到」只用 `❌未开始` / `p.N` / `✅全` |
| `deadlines.md` | `导航.py` | 周次表 `\| W1 \| 07-27 ~ 08-02 \|`（算「今天第几周」的唯一依据）；时间线表 5 列：`\| 日期 \| 周 \| 课程 \| 事项 \| 权重 \|`，日期列以 `MM-DD` 开头 |
| 〃 | 〃 | 事项含 `due` `截止` `tute` `quiz` `exam` `考` `交` 等词才算硬截止；只含 `lecture` 的不算；日期或事项里有 `已交` `已提交` `已结清` 的不再显示 |
| `学习日志.md` | `导航.py` · `检查.py` `[1·语义][2][11]` | `# 📍 当前进度速查` 下一张**恰好 3 列**的表（课 / 状态一句话 / 优先级），表格行里不许出现页码；`## ⏸️ 当前断点` 一节，后面紧跟另一个 `## ` 标题 |
| `学时记录.md` | `检查.py` `[4]` | `## 累计` 表，每行 `\| **<key>** \| **X h Y min** \|`，再加一行 `总计`；每门课一节 `## <key> …`，明细行第一格以 `MM-DD` 开头、第三格是时长；节末 `**小计：X h Y min**` |
| `提醒.tsv` | `提醒.py` | `类型<TAB>规则<TAB>文字`；类型 `RANGE 起..止` · `WEEKLY 周几;from=;until=` · `EVERY 间隔天数;from=;days=` |
| `活动会话.tsv` | `导航.py` | Tab 分隔：开始时间 · 类型（学 / 作业 / 总控）· 在做什么 · `active` 或 `done` · [可选] 收尾时间 |
| `公告.md` | 人工 | 每门课一节，节名 = `## <name> <code>`；不许新开同义节（按课程名检索会漏）|
| `规则同步.tsv` | `检查.py` `[13]` | 见 [架构说明 §7](架构说明.md#7-规则的三种存放方式) |

改了格式就同步改脚本。脚本都在 `shared/工具/`，只用标准库。

## 5. 加一门课 / 删一门课

**加：**

1. `配置.json` 的 `courses` 加一项
2. `mkdir -p <key>/{课件/_预扫,字幕,笔记,收尾卷,作业,tute,教材,例卷,录音}`，写一份 `<key>/CLAUDE.md`
3. 台账加一节 `## <key> <code> · lecture … · tute …` 和 7 列表头
4. 学时记录的累计表加一行 `| **<key>** | **0 h 00 min** |`（累计 0 且没有小计节的课视为一致）
5. 公告加一节 `## <name> <code>`
6. `python3 shared/工具/检查.py`

**删：** 反过来做；`检查.py [3]` 会抓出所有还在引用这门课的路径。

## 6. 改规则之后

改了 `CLAUDE.md` 的某条规则：

1. `python3 shared/工具/检查.py` —— 如果这条在 `规则同步.tsv` 里登记过，`[13]` 会报「主文件那段改过了（hash 旧 → 新）」
2. 打开报出的下游文件（`.claude/commands/*.md`、`inject-time.sh`），看要不要跟着改
3. 核完把新哈希写回 `规则同步.tsv` 那一行的第 5 列

新加一条「下游流程文件必须落实」的规则时，在 `规则同步.tsv` 里登记一行。
建议同时在 `shared/规则档案.md` 顶部记一条：哪天、为什么、原话是什么。下次想改它时，你会感谢当时的自己。

## 7. 调整三道门

hook 注册在 `.claude/settings.json`：

| 想要 | 改法 |
|---|---|
| 暂时关掉收尾门 | 删掉 `Stop` 那一段，或在 `stop-check.sh` 开头 `exit 0` |
| 每条消息少注入一点 | 编辑 `inject-time.sh` 里的 `READ_BEFORE` / `GRADE_RULE` / `QUIZ_EN` |
| 开场多注入一样东西 | 在 `inject-context.sh` 里拼进 `BODY`，最后由 `jq` 转成 JSON |

改完 hook 一定验 JSON：

```bash
bash .claude/hooks/inject-context.sh | python3 -c 'import json,sys; json.load(sys.stdin); print("ok")'
echo '{}' | bash .claude/hooks/inject-time.sh | python3 -c 'import json,sys; json.load(sys.stdin); print("ok")'
```

## 8. 常见改法

| 场景 | 改法 |
|---|---|
| **考试不是英文** | 删 `CLAUDE.md` 的「术语保持英文」「核心 explanation 直接用英文写」两节，改出题语言规则，删 `inject-time.sh` 的 `QUIZ_EN`，再处理 `[13]` 的提示 |
| **没有录音** | 台账「字幕」列填 `➖不需要`；对照表只保留「📗 其他资料对应段落」 |
| **LMS 不是 Canvas / Ed** | `shared/API笔记/` 是原项目探过的 API，换成你自己的；`ed抓取书签.md` 那个 bookmarklet 对大多数网页都能用 |
| **不用 LaTeX** | 看板改成 Markdown：`/next` 里把编译步骤换成 `shared/工具/md2pdf.py`，或者干脆只在对话里给结论 |
| **不是中午起床** | 改 `CLAUDE.md`「他的作息」一节；`规则同步.tsv` 里 `NO-MORNING` 那行一并删掉 |
| **一个人用不需要并行会话** | 规则照旧能用；分区和交接单只是多一份保险 |
