# 接入其他模型

> 这套架构不绑定 Claude。规则（`CLAUDE.md`）、命令（`.claude/commands/`）、三道门（`.claude/hooks/`）都是纯文本和脚本，
> 换哪个模型都能用。有两条路，**共用同一份 `.env` 配置**，可以随时切换。

## 两条路怎么选

| | **A：Claude Code + 别家模型** | **B：自带运行时 `./study`** |
|---|---|---|
| 需要装什么 | Claude Code（免费，不需要 Anthropic 账号）| 只要 Python 3.9+ |
| 能接的模型 | 有 **Anthropic 兼容接口**的：DeepSeek · Kimi · 智谱 GLM；其他的经 LiteLLM 代理也行 | **任何 OpenAI 兼容接口**：上面那些 + OpenAI · 通义 · OpenRouter · Ollama 本地模型 · vLLM … |
| 三道门 · 规则 · `/学` `/作业` `/总控` | ✅ | ✅（同一套 hook 脚本、同一套命令文件）|
| 子 agent（并行审查、批量预扫）| ✅ | ❌ |
| MCP（邮箱、浏览器…）| ✅ | ❌ |
| 联网搜索 | 看厂商是否支持 | ❌ |
| 把 PDF 发到侧边面板 | ✅（桌面版）| 用系统程序打开 |
| 界面 | Claude Code 的终端 / 桌面版 | 简单的终端对话 |

**建议**：模型在 A 的支持列表里，就走 A，功能最全；想用 OpenAI、通义、本地模型，或者不想装 Claude Code，走 B。

## 第一步：配置 .env

```bash
cp .env.example .env
$EDITOR .env
```

| 变量 | 必填 | 说明 |
|---|:-:|---|
| `STUDY_PROVIDER` | ✅ | 预设名：`deepseek` · `kimi` · `glm` · `qwen` · `openai` · `openrouter` · `anthropic` · `ollama`（见 [`shared/模型预设.json`](../shared/模型预设.json)）|
| `STUDY_API_KEY` | ✅ | 你的 API key（`ollama` 不需要）|
| `STUDY_MODEL` | 视预设 | 模型名。预设给了默认值的可以不填；`glm` `qwen` `openai` `openrouter` `ollama` 必须填 |
| `STUDY_SMALL_MODEL` | | 轻量任务用的小模型（Claude Code 的 Haiku 档、收尾门的行动项审计）|
| `STUDY_BASE_URL` | | 不用预设，直接填 OpenAI 兼容地址（例：`http://localhost:8000/v1`）|
| `STUDY_STREAM` | | 设 `0` 关掉流式输出（个别中转服务的流式有问题时）|

`.env` 在 `.gitignore` 里，不会被提交。**key 只放这里，别贴进对话、别写进别的文件。**

## 路线 A：Claude Code + 别家模型

```bash
python3 shared/工具/切换模型.py deepseek     # 或 kimi · glm
claude                                       # 重启 Claude Code，进去后 /status 核对
```

脚本把 `.env` 里的配置写进 `.claude/settings.local.json` 的 `env` 块（同样只在本机生效）。只改下面这几个变量，别的设置原样保留：

| 变量 | 值 |
|---|---|
| `ANTHROPIC_BASE_URL` | 厂商的 Anthropic 兼容地址 |
| `ANTHROPIC_AUTH_TOKEN` | `.env` 里的 key |
| `ANTHROPIC_MODEL` · `ANTHROPIC_DEFAULT_OPUS_MODEL` · `ANTHROPIC_DEFAULT_SONNET_MODEL` · `CLAUDE_CODE_SUBAGENT_MODEL` | 主模型 |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | 小模型 |

| 想要 | 命令 |
|---|---|
| 看现在用的是哪个 | `python3 shared/工具/切换模型.py` |
| 切回 Anthropic 官方 | `python3 shared/工具/切换模型.py claude` |
| 接任意 Anthropic 兼容地址 | `python3 shared/工具/切换模型.py custom <地址>` |

> ⚠️ shell 里如果设了 `ANTHROPIC_API_KEY`，它可能盖掉这里的配置、仍然走 Anthropic 计费。切换前先 `unset ANTHROPIC_API_KEY`。

**只有 OpenAI 格式接口的模型想用 Claude Code**：起一个 [LiteLLM](https://docs.litellm.ai/) 代理，它能把 Anthropic 格式的请求转成各家的格式，然后 `切换模型.py custom http://localhost:4000`。这一步要自己按 LiteLLM 文档配，比走路线 B 麻烦。

## 路线 B：自带运行时 ./study

```bash
./study                      # 交互模式
./study -p "跑一下体检"       # 单次模式：跑完一个回合就退出
./study --yes                # 工具调用一律不问
./study --provider kimi --model kimi-k3     # 临时换模型
```

**它做的事和 Claude Code 一样：**

| 环节 | 怎么实现 |
|---|---|
| 规则 | 每个会话把 `CLAUDE.md` 全文放进系统提示 |
| 开场门 · 消息门 · 收尾门 | 按 Claude Code 的 hook 协议调用 `.claude/settings.json` 里登记的同一批脚本（stdin JSON、`additionalContext`、退出码 2 拦回）|
| 收尾门拦回 | 把拦截原因回给模型，**同一回合里修好再结束**（只拦一次，防死循环）|
| `/学` `/作业` `/总控` … | 读 `.claude/commands/<名字>.md`，参数替换 `$ARGUMENTS` |
| 工具 | `read_file` · `write_file` · `edit_file` · `list_dir` · `grep` · `bash` · `ask_user`（= AskUserQuestion）· `open_file`（= SendUserFile）|
| 会话记录 | `.study/sessions/*.jsonl`（Claude Code 的 transcript 格式，收尾门的行动项审计会读它）|

**内置命令**：`/help` · `/commands` · `/model` · `/clear`（开新会话）· `/exit`。行尾加 `\` 可以多行输入，Ctrl-C 打断当前回合。

**权限：**

| 操作 | 默认 |
|---|---|
| 读文件、列目录、搜索 | 直接执行 |
| 写 / 改**项目里**的文件 | 直接执行（终端上会显示）|
| 写 / 改项目外的文件 | 先问 |
| `bash`：白名单里的只读命令（`python3 shared/工具/…` · `ls` · `grep` · `pdftotext` · `git status` …）| 直接执行 |
| `bash`：其他命令，或带重定向、串联、命令替换的 | 先问（`y` 这一次 · `a` 本会话都允许 · `n` 拒绝）|
| 单次模式 `-p` 且没给 `--yes` | 需要问的一律拒绝 |

**规则里提到、这里没有的东西**（子 agent、MCP、联网搜索、会话列表）：运行时会告诉模型「这里没有，跳过那一步并说明」，不会假装做了。

## 预设一览

| 预设 | OpenAI 兼容地址（路线 B）| Anthropic 兼容地址（路线 A）| 默认模型 |
|---|---|---|---|
| `deepseek` | `https://api.deepseek.com/v1` | `https://api.deepseek.com/anthropic` | `deepseek-v4-pro` / 小：`deepseek-flash` |
| `kimi` | `https://api.moonshot.ai/v1` | `https://api.moonshot.ai/anthropic` | `kimi-k3`（路线 A 用 `kimi-k3[1m]`）|
| `glm` | `https://open.bigmodel.cn/api/paas/v4` | `https://open.bigmodel.cn/api/anthropic` | 自己填 |
| `qwen` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | — | 自己填 |
| `openai` | `https://api.openai.com/v1` | — | 自己填 |
| `openrouter` | `https://openrouter.ai/api/v1` | — | 自己填 |
| `anthropic` | `https://api.anthropic.com/v1` | （官方，用 `切换模型.py claude`）| `claude-sonnet-5-5` |
| `ollama` | `http://localhost:11434/v1` | — | 自己填 |

> 模型名会随厂商更新。预设里的默认值以 2026 年 10 月各家文档为准，**以厂商当前文档为准**，用 `STUDY_MODEL` 覆盖即可。
> 加新厂商：在 `shared/模型预设.json` 里照格式加一项。

## 选模型的建议

这套规则很长（`CLAUDE.md` 约 2 万 token），而且要求模型**严格守规矩**：一块不超过 5 页、出题选项带标号、批改先贴题干、改账本前先查。所以：

- **选各家的旗舰模型**，而且要支持工具调用（function calling）。小模型常常记不住长规则，或者工具调用格式出错。
- **上下文至少 64K**。运行时会在超出 `STUDY_MAX_CHARS`（默认 25 万字符）时，从最早的工具输出开始省略。
- 推理模型（带「思考」的）可以用，思考过程会在终端里以暗色显示。

## 常见问题

<details>
<summary><b>HTTP 401 / 403</b></summary>

key 不对，或者 key 和地址不配套（例：DeepSeek 的 key 配了 Kimi 的地址）。核对 `.env` 的 `STUDY_PROVIDER` 和 `STUDY_API_KEY`。
</details>

<details>
<summary><b>HTTP 400：model not found / 模型不存在</b></summary>

模型名过时了。去厂商文档查当前的模型名，填进 `.env` 的 `STUDY_MODEL`。
</details>

<details>
<summary><b>输出卡住、或者报流式相关的错误</b></summary>

个别中转服务的流式输出不规范。在 `.env` 里加 `STUDY_STREAM=0`。
</details>

<details>
<summary><b>模型不调用工具，只会凭空回答</b></summary>

换更强的模型。也可以在对话里明确说「先用工具查」。
</details>

<details>
<summary><b>路线 A 切换后 Claude Code 还在用 Claude</b></summary>

① 重启 Claude Code；② `unset ANTHROPIC_API_KEY`；③ 进去后 `/status` 看 Base URL 和模型。
</details>
