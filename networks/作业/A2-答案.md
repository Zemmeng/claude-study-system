# A2 答案（草稿 · 示例 · 虚构）

**Q1.** At the transport layer the unit is a segment. At the network layer the unit is a frame.

**Q2.** Maximum data rate = 2 × B × V = 2 × 4000 × 8 = 64,000 bit/s, so the channel can carry 64 kbps.

**Q3.** The five-layer model has the application, transport, network, link and physical layers. Each layer adds its own header to the data from the layer above, which is called encapsulation. On the receiving side each layer removes its header.

**Extra.** I also checked the answer with the Shannon formula C = B log2(1 + S/N), assuming an SNR of 30 dB, which gives about 40 kbps, so the Nyquist result is an upper bound.
