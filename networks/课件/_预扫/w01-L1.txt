What Is a Network?
       • Hosts (end systems) run applications
       • Links carry bits between nodes (copper, fibre, radio)
       • Switches and routers forward data towards its destination
    The hard part is not any single piece; it is making millions of independently built pieces
    work together.

===== w01-L1 viewer p.3 =====
Why Layers? A Postal Analogy
    Sending a letter abroad: you write it, the post office sorts it, a plane carries it.
       • You do not know which plane is used – and you should not need to
       • Each step offers a service to the step above and uses the one below
       • Any step can be replaced (a train instead of a plane) without changing the others
    Layering = the same idea applied to network software.

===== w01-L1 viewer p.4 =====
The Five-Layer Model
        Layer         Job                                     Example protocol       Unit of data
        Application   what the user program says              HTTP, DNS              message
        Transport     process-to-process delivery             TCP, UDP               segment
        Network       host-to-host delivery across networks   IP                     packet
        Link          delivery over one hop                   Ethernet, Wi-Fi        frame
        Physical      bits on the medium                      copper, fibre, radio   bit

Encapsulation
    Each layer wraps the data from above with its own header.
                       Application                       message
                         Transport               TCP     message
                          Network           IP   TCP     message
                               Link   Eth   IP   TCP     message

===== w01-L1 viewer p.6 =====
Protocol, Service, Interface
               Term        Meaning
               Service     what a layer offers to the layer above
               Interface   how the layer above asks for that service
               Protocol    the rules two peer layers on different machines follow
                           to talk
    Changing a protocol inside one layer should not break the layers around it.
