What Is a Network?
       • Hosts (end systems) run applications
       • Links carry bits between nodes (copper, fibre, radio)
       • Switches and routers forward data towards its destination
    The hard part is not any single piece; it is making millions of independently built pieces
    work together.

===== w01-L1 viewer p.3 =====
Why Layers? A Postal Analogy
    Sending a letter abroad: you write it, the post office sorts it, a plane carries it.
       • You do not know which plane is used – and you should not need to
       • Each step offers a service to the step above and uses the one below
       • Any step can be replaced (a train instead of a plane) without changing the others
    Layering = the same idea applied to network software.

Signals and Bandwidth
       • A signal varies over time; its content spans a range of frequencies
       • Bandwidth B = the width of the usable frequency range, in hertz (Hz)
       • A channel passes frequencies from f1 to f2 , so B = f2 − f1
     Example: a telephone line passing 300 Hz to 3300 Hz has B = 3000 Hz.

===== w02-L1 viewer p.5 =====
Nyquist: A Noiseless Channel
     For a noiseless channel of bandwidth B Hz and signals with V distinct levels:
                                  max data rate = 2B log2 V bits/s
     Example. B = 3000 Hz, binary signal (V = 2):
                                   2 × 3000 × log2 2 = 6000 bits/s
     More signal levels give more bits per symbol – but noise limits how many levels we can
     tell apart.
